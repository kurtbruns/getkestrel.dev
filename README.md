# getkestrel.dev

The source for **[getkestrel.dev](https://getkestrel.dev)**, the website for [Kestrel](https://github.com/kurtbruns/kestrel), a small, open-source, self-hosted newsletter app.

Looking for Kestrel itself? The app, its issues, and its setup guides live in the [kestrel repo](https://github.com/kurtbruns/kestrel). This repo is only the website: the landing page, the `/docs/` guides as rendered on the site, and a contact form. The guides are synced from kestrel at build time, so a fix to one belongs in kestrel's `docs/`, not here.

To work on the site itself, see [CONTRIBUTING.md](CONTRIBUTING.md).
